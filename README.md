## Запуск у Visual Studio

Відкрийте [lab09.sln](lab09.sln) у Visual Studio з компонентом **Розробка класичних програм мовою C++** (MSVC v143 та Windows SDK; склад компонентів — [.vsconfig](.vsconfig)). Виберіть **x64 / Debug** і запустіть консольний проєкт через **Ctrl+F5**. Докладні вказівки: [VISUAL-STUDIO.md](VISUAL-STUDIO.md).

## Завдання

Варіант 1. Від класу Base з віртуальною функцією myname(), яка виводить назву класу, створити DerA та DerB; від них множинним успадкуванням отримати DerAB. Перевизначити myname() у кожному класі. Створити по звичайному об'єкту кожного класу й викликати myname(). Створити масив чотирьох покажчиків Base*, записати в нього адреси динамічних об'єктів усіх чотирьох класів і викликати myname() через покажчики. Пояснити всі виклики, сформувати звіт, зробити висновки й відповісти на контрольні запитання.

## Файли

- `main.cpp` — вихідний код.
- `build.ps1` — відтворювана збірка у PowerShell.
- `expected_output.txt` — фактичний вивід перевіреного запуску.

## Збирання

Потрібні GCC/MinGW з підтримкою C++14 та PowerShell. Перевірено GCC 16.2.0 (w64devkit). Запускайте команди в каталозі цієї лабораторної роботи. Для всіх команд `g++` і `ar` мають належати до одного комплекту MinGW.

Якщо каталог `bin` компілятора вже додано до `PATH`:

```powershell
.\build.ps1
```

Або передайте шлях до власного каталогу `bin` компілятора:

```powershell
.\build.ps1 -CompilerDirectory '..\mingw64\bin'
```

Окремі команди збірки:

```text
g++ -std=c++14 -Wall -Wextra -pedantic main.cpp -o main.exe
```

## Запуск і перевірка

Для інтерактивного запуску:

```powershell
.\main.exe
```

Для повторення перевіреного запуску та порівняння рядків із записаним результатом:

```powershell
cmd /c ".\main.exe > actual_output.txt"
if ($LASTEXITCODE -ne 0) { throw 'Program failed' }
Compare-Object (Get-Content .\expected_output.txt) (Get-Content .\actual_output.txt)
```

Порожній результат `Compare-Object` означає збіг рядків. Каталог `bin` MinGW залиште в `PATH`, щоб Windows могла знайти потрібні бібліотеки середовища виконання. Програма перевіряє результати та завершується з кодом `0` після успішного виконання.

Очікувані перевірки:

- Для звичайних об'єктів myname послідовно друкує This is class Base, DerA, DerB, DerAB.
- Адреси спільного Base у DerAB, отримані через обидві гілки, збігаються: Shared Base subobject: yes.
- Через чотири Base* друкуються ті самі чотири фактичні назви класів.
- Усі динамічні об'єкти видалено: Dynamic objects deleted: yes.
- Після завершення області видимості виведено Live objects after scope: 0.
- Програма друкує Self-checks: PASS і завершується з кодом 0.
